# APU Smart Shuttle 🚍

## About the Project

APU Smart Shuttle is an intelligent shuttle tracking and notification system designed to improve transportation convenience for Asia Pacific University (APU) students and staff.

The system allows users to view shuttle schedules, track shuttle locations in real time, check estimated arrival times (ETA), and receive smart notifications about shuttle arrivals, traffic congestion and weather conditions.

## Key Features

- Student and staff authentication
- Shuttle timetable and route selection
- Real-time shuttle GPS tracking
- Dynamic estimated arrival time (ETA)
- Traffic congestion monitoring
- Rain forecast and weather alerts
- Smart departure reminders
- Automated push notifications

## Technologies Used

- Flutter
- Firebase Authentication
- Cloud Firestore
- Firebase Cloud Messaging
- Google Maps Platform
- Weather API

## Project Objective

To provide a smarter, more convenient and reliable shuttle transportation experience for the APU community.

## Project Status
